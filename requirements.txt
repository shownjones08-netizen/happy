#  1) cloudflared   — public tunnel for the REST API (auto-downloaded on first run)

#
#  2) adb (Android Platform Tools) — "Phone VPS" OTP auto-read feature
#       Debian/Ubuntu : sudo apt install -y android-tools-adb
#       Manual        : https://developer.android.com/tools/releases/platform-tools
#
#  3) Node.js + npm — WhatsApp bridge (wa_bridge/index.js) ONLY
#       Install: https://nodejs.org  (v18+ recommended)
#       Then   : cd wa_bridge && npm install
#
#  4) ffmpeg — optional, only if you add audio/video handling later
#       Debian/Ubuntu : sudo apt install -y ffmpeg
#
#  5) Build tools (some wheels need them on minimal images)
#       Debian/Ubuntu : sudo apt install -y build-essential python3-dev libffi-dev libssl-dev
#
